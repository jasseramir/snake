# 🐍 Snake Game

A simple Snake game built using **HTML**, **CSS**, and **Vanilla JavaScript** with the HTML5 Canvas API.

## ✨ Features

- 🎮 Mobile controls
- ⌨️ Keyboard controls (WASD + Arrow Keys)
- 🍎 Random food generation
- 🟢 Snake grows after eating food
- 🚫 Prevents 180° turns
- 💥 Collision with walls
- 🐍 Collision with the snake's own body
- 📊 Live score
- 🔄 Restart after Game Over

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- HTML5 Canvas API

## 🎯 Controls

| Action | Key |
|--------|-----|
| Up | W / ↑ |
| Down | S / ↓ |
| Left | A / ← |
| Right | D / → |

You can also use the on-screen buttons on mobile devices.

## 🚀 Run

Clone the repository:

```bash
git clone https://github.com/jasseramir/snake.git
```

Open `index.html` in your browser.

No dependencies or installation required.
